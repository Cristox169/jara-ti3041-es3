# Commits requeridos ES2

1. `etapa-0-entorno` - proyecto ES2 operativo.
2. `etapa-1-modelo` - modelo Producto y migraciones.
3. `etapa-2-admin` - superusuario y Django Admin.
4. `etapa-3-bd` - fixture de 40 productos y catálogo consultando ORM.
5. `entrega-final` - documentación y entrega.

Los commits deben realizarse en el nuevo repositorio de ES2 y no en el repositorio de ES1.

## Trazabilidad ES3

Para el repositorio de esta evaluación, la progresión solicitada por la guía es:

1. `etapa-0-entorno` - ES2 operativo con la base poblada.
2. `etapa-1-crud` - CRUD web de productos.
3. `etapa-2-reportes` - reportes agrupado y filtrado con ORM.
4. `etapa-3-clientes` - consultas de clientes, validaciones, CSRF y sesiones.
5. `entrega-final` - documentación, verificación y ZIP final.
